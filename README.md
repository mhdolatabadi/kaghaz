# کاغذ (Kaghaz)

اپ یادداشت‌برداری دست‌نویس و تایپی با Flutter، برای اندروید (گوشی و تبلت) و وب.

## امکانات فعلی

**کتابخانه**
- پوشه و زیرپوشه با تعداد نامحدود سطح، رنگ برای هر پوشه
- جابه‌جایی دفترچه‌ها و پوشه‌ها با نگه‌داشتن و کشیدن روی پوشه، نوار کناری یا مسیر بالای صفحه، یا از منوی «انتقال به…»، همراه با دکمه‌ی بازگردانی
- همه‌ی دفترچه‌ها، علاقه‌مندی‌ها، جستجو در نام دفترچه‌ها و پوشه‌ها، مرتب‌سازی (آخرین تغییر، نام، تاریخ ساخت)
- کاور رنگی دفترچه و انتخاب نوع کاغذ هنگام ساختن
- نوار کناری ثابت در تبلت و وب، کشوی کناری در گوشی

**صفحه‌ها**
- صفحه‌های دست‌نویس و متنی، با پیش‌نمایش
- مرتب کردن صفحه‌ها با کشیدن (در فهرست صفحه‌ها و پنل کناری ویرایشگر)
- کپی صفحه، انتقال صفحه به دفترچه‌ی دیگر، افزودن صفحه بعد از صفحه‌ی فعلی

**ویرایشگر**
- نوار ابزار شناور: قلم (خودکار یا خودنویس با حساسیت به فشار)، هایلایتر، پاک‌کن خطی، انتخاب کمندی، شکل (خط، فلش، مستطیل، بیضی)، جابه‌جایی صفحه
- با زدن دوباره روی ابزار انتخاب‌شده، تنظیمات آن باز می‌شود: نوع قلم، ضخامت با پیش‌نمایش، رنگ‌ها
- انتخاب کمندی: جابه‌جا کردن، کپی، تغییر رنگ و حذف خط‌های انتخاب‌شده
- واگرد و ازنو، زوم و جابه‌جایی با دو انگشت
- تشخیص قلم: وقتی قلم دیده شود، لمس انگشت فقط جابه‌جا می‌کند. سر پاک‌کن قلم هم پاک می‌کند.
- زمینه‌ی صفحه: ساده، خط‌دار، شطرنجی، نقطه‌ای

**عمومی**
- رابط کاربری فارسی و راست‌به‌چپ، فونت وزیرمتن، اعداد فارسی
- ذخیره‌ی خودکار و آفلاین در SQLite (روی وب در IndexedDB/OPFS)

## ساختار

```
lib/
  app.dart                     زبان و صفحه‌ی شروع
  core/theme.dart              رنگ‌ها، تایپوگرافی و تم روشن/تیره
  core/db/                     دیتابیس Drift و providerهای Riverpod
  core/widgets/                دیالوگ‌ها و انتخابگر پوشه/دفترچه
  features/library/            کتابخانه: نوار کناری، پوشه‌ها، کاور دفترچه‌ها
  features/notebooks/          فهرست صفحه‌های یک دفترچه
  features/editor/             ویرایشگر صفحه، نوار ابزار و پنل صفحه‌ها
  features/ink/                موتور رسم: مدل خط، کنترلر، painter و بوم
```

خط‌ها به‌صورت JSON در ستون `ink` جدول صفحه‌ها ذخیره می‌شوند.

## اجرا

```bash
flutter pub get
flutter run -d chrome        # وب
flutter run                  # اندروید
flutter test
```

بعد از تغییر جدول‌های دیتابیس، کد Drift را دوباره بسازید:

```bash
dart run build_runner build
```

فایل‌های `web/sqlite3.wasm` و `web/drift_worker.js` باید با نسخه‌ی پکیج‌های `sqlite3` و `drift` در `pubspec.lock` هم‌خوان باشند. اگر این پکیج‌ها را به‌روز کردید، این فایل‌ها را هم از صفحه‌ی releases همان پکیج‌ها دوباره دانلود کنید.

## کارهای بعدی

- فاز ۲: ورود PDF و حاشیه‌نویسی، عکس، جعبه‌ی متن روی صفحه، خروجی PDF، قالب‌ها و اندازه‌های صفحه، سطل زباله
- فاز ۳: جستجو در دست‌خط و تبدیل آن به متن، ضبط صدا، برچسب، قفل یادداشت، همگام‌سازی ابری

فونت وزیرمتن تحت مجوز SIL OFL است (`assets/fonts/OFL.txt`).
