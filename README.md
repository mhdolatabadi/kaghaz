# کاغذ (Kaghaz)

اپ یادداشت‌برداری دست‌نویس و تایپی با Flutter، برای اندروید (گوشی و تبلت) و وب.

## امکانات فعلی

- دفترچه‌ها: ساختن، تغییر نام، حذف
- صفحه‌های دست‌نویس و متنی، با پیش‌نمایش در فهرست صفحه‌ها
- قلم با حساسیت به فشار، هایلایتر، پاک‌کن خطی، و انتخاب رنگ و ضخامت
- واگرد و ازنو، زوم و جابه‌جایی با دو انگشت یا ابزار جابه‌جایی
- تشخیص قلم: وقتی قلم دیده شود، لمس انگشت فقط جابه‌جا می‌کند (جلوگیری از کشیدن با کف دست). سر پاک‌کن قلم هم پاک می‌کند.
- زمینه‌ی صفحه: ساده، خط‌دار، شطرنجی، نقطه‌ای
- رابط کاربری فارسی و راست‌به‌چپ
- ذخیره‌ی خودکار و آفلاین در SQLite (روی وب در IndexedDB/OPFS)

## ساختار

```
lib/
  app.dart                     تم، زبان و صفحه‌ی شروع
  core/db/                     دیتابیس Drift و providerهای Riverpod
  core/widgets/                دیالوگ‌های مشترک
  features/ink/                موتور رسم: مدل خط، کنترلر، painter و بوم
  features/notebooks/          فهرست دفترچه‌ها و صفحه‌ها
  features/editor/             ویرایشگر صفحه و نوار ابزار
```

خط‌ها به‌صورت JSON در ستون `ink` جدول صفحه‌ها ذخیره می‌شوند.

## اجرا

```bash
flutter pub get
flutter run -d chrome        # وب
flutter run                  # اندروید
flutter test
```

بعد از تغییر جدول‌های دیتابیس، کد Drift را دوباره بسازید:

```bash
dart run build_runner build
```

فایل‌های `web/sqlite3.wasm` و `web/drift_worker.js` باید با نسخه‌ی پکیج‌های `sqlite3` و `drift` در `pubspec.lock` هم‌خوان باشند. اگر این پکیج‌ها را به‌روز کردید، این فایل‌ها را هم از صفحه‌ی releases همان پکیج‌ها دوباره دانلود کنید.

## کارهای بعدی

ورود PDF و حاشیه‌نویسی، عکس، انتخاب و جابه‌جایی خط‌ها (lasso)، جستجو، خروجی PDF، همگام‌سازی ابری.
